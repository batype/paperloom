# 演示与发布文案草稿

15 秒演示：打开示例 → 技术手册切为杂志文章 → 点击检查中一个问题定位源码 → 生成 PDF 校样 → 下载 PDF。

发布文案：

今天做了 Paperloom 墨页：把 Markdown 变成可交付的文档。同一份内容切换技术手册、杂志文章和正式报告；交付前找出断开的文内链接和跳级标题；生成真正的中文 PDF 校样，保留可选文字，而不是截图。也能带走独立 HTML 和原始 MD。React + Vite，浏览器本地排版，MIT 开源。

演示：https://batype.github.io/paperloom/
源码：https://github.com/batype/paperloom
