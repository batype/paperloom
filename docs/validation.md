# 验证记录

2026-10-30，Node.js 24、TypeScript 7、Vite 8；浏览器检查使用 Chromium 内核的应用内浏览器。

## 自动检查

`npm test` 通过 16 项有实际输入/输出的检查，覆盖：

- 中文、精确字符串、内联格式、代码高亮和表格。
- 原始 HTML / script 转义和危险协议链接。
- 图片的本地嵌入与外部图片占位。
- 中文锚点、重复标题与后缀碰撞，失效链接、跳级标题及源码行号。
- 仅在代码围栏外解释分页标记。
- 自带样式、内容安全策略和目录的独立 HTML。
- PDF 的标题、可选择文字、表格、列表、嵌入字体、目录、PNG 和长代码；调用真实 pdfmake 引擎生成字节，不只检查模型。
- 文档大小/行数边界、排版参数校验和文件名处理。

`npm run build` 完成类型检查与正式构建。依赖升级到 markdown-it 14.3.3 后，npm 安装审计结果为 0 项已报告漏洞；这不构成未来无漏洞的保证。

## 真实浏览器流程

- 默认示例即时渲染；切换排版保留原文。
- 输入跳级标题、失效锚点、远程图片和 script；检查显示对应行号，脚本只作为文字出现。
- 检查结果点击定位；页面刷新后恢复正文与排版设置。
- 模板替换后撤销，恢复之前的内容。
- UTF-8 `.md` 文件实际导入；本地 PNG 经插图入口嵌入，图像解码为 480 × 180。
- PDF 校样实际生成、取消后重试；下载含中文、目录和本地图片的 PDF。
- HTML / MD 经下载控件获取实际文件；原始链接在 MD 中保留，HTML 锚点重写正确，嵌入 PNG 数据完整。
- 导出 HTML 在独立 HTTP 来源打开，中文、排版与内嵌图正常，控制台没有警告/错误。
- 390 × 844 手机暗色布局检查，页面没有水平溢出；桌面亮暗界面正常。PDF 查看器的实现取决于浏览器。

## PDF 视觉核对

使用 pypdf 提取浏览器下载 PDF 的中文、代码与表格，确认不是截图。含目录和图片的 PDF 为 2 页，包含实际图像对象。

对三个主题分别生成 PDF，Poppler 渲染后逐页检查：技术手册 2 页、Letter 杂志文章 2 页、含目录和手动分页的正式报告 3 页。修复了表头单独挂页的问题，并让标题与后面的短段落保持在一起。字体、表格、页码及章节转换清晰，无已观察到的重叠或文字裁切。

## 未覆盖与边界

没有实际覆盖 Safari、Firefox、iOS/Android 原生 PDF 查看器、屏幕阅读器、多标签同时编辑冲突或浏览器存储被禁用的所有组合。未承诺所有 Unicode/Emoji 字形、任意复杂嵌套表格、超长单元格、远程图片、公式或图表渲染。阅读预览和 PDF 是不同排版引擎，请以真实 PDF 校样为准。
